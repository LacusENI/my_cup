## 描述

32×32 通用寄存器堆，`$0` 恒为 0。

## 端口

input
- `clk`：时钟信号
- `reg_src1(5)`：读端口 1 的寄存器号
- `reg_src2(5)`：读端口 2 的寄存器号
- `reg_dst(5)`：写端口寄存器号
- `wb_data(32)`：写入数据
- `reg_write`：写使能

output
- `rs1_data(32)`：读端口 1 的数据
- `rs2_data(32)`：读端口 2 的数据

## 行为

- 组合读；读 `$0` 返回 0；
- 上升沿写；只有 `reg_write=1` 且 `reg_dst != 0` 时才写入。
